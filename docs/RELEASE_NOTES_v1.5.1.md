# DropSendTo v1.5.1

公開日: 2026-11-04。v1.5.0 以降の修正。Windows 10 22H2 以降 / Windows 11、x64。

## 修正

- `PREFIX PASSTHROUGH` が Prefix 待機中でも前面アプリへ Prefix キーを送出するよう修正しました。外部マクロ入力の受付設定にかかわらず本ツールのショートカット判定を回避し、待機状態を維持します。
- マウスジェスチャの小さな連続移動を取りこぼしにくくし、UI が処理中でも検出を継続するよう改善しました。「マウスフォロー」では描いた円の中心へ表示し、表示倍率の異なるディスプレイ間でも位置を補正します。
- タブ名と検索ボックスが、表示倍率の異なるディスプレイへの移動やウィンドウのサイズ変更に追従するよう修正しました。画面上端で上に収まらない場合は下へ表示し、検索からスロットへ移るキー操作も配置に合わせます。

## 更新・互換性

- **通常版**: `DropSendTo_win-x64_v1.5.1.zip`。.NET 10 Desktop Runtime が必要です。
- **ランタイム同梱版**: `DropSendTo_Portable_win-x64_v1.5.1.zip`。.NET の別途インストールは不要です。設定保存先は通常版と同じ `%AppData%\DropSendTo` です。
- 設定形式のバージョンは37を維持します。既存の設定と操作を引き継げます。
- 更新前に設定を退避し、DropSendTo を終了して、利用中と同じ配布形式のファイルへ置き換えてください。サインイン時起動を登録済みの場合は実行ファイルを同じ場所へ置いてください。

## 検証

- Release 構成の全780テスト、ビルド、フォーマット、版識別子・配布成果物の回帰チェックを実施しました。
- 100%・150% の2画面で、ジェスチャによる表示・非表示、タブ名と検索ボックスの画面間移動・画面端補正・キー操作を隔離設定で検証しました。ジェスチャ入力は検出処理へ渡す自動検証で、物理マウスによる円運動は未検証です。
- 日英・明暗・通常／最小サイズの WPF 表示と、設定の保存・復元、モデルレス画面の開閉を検証しました。
