# DropSendTo v1.4.1

公開対象: v1.3.0 以降の変更。Windows 10 22H2 以降 / Windows 11、x64。

## 追加・改善

- 「DropSendTo について…」を開いたときに GitHub の最新版を確認し、新版があれば該当リリースページを開くダウンロードボタンを表示。再確認、通信失敗表示、開発版の判定除外、日英表示に対応。
- 設定を専用のモデルレス画面へ集約し、メイン操作を続けながら表示・ショートカット・タブ・起動・データ管理の設定を変更可能に。
- 前面アプリの実行ファイル名・タイトル等に応じたタブの自動切替を追加。一時固定・優先順位・未一致時の切替先に対応（既定 OFF）。
- Windows サインイン時に DropSendTo を起動するユーザー単位の登録・解除を設定画面へ追加。
- スロット検索にあいまい検索、AND/OR、除外、先頭・末尾一致などの検索演算子を追加。
- Macro Script に日時生成、パス分解、ファイル操作、外部プロセスの待機・出力取得、TRY/CATCH、ウィンドウ検索・アクティブ化、行・分割ループを追加。Tips・スニペット・サンプルも拡充。
- `MOUSEMOVEDISPLAY` で Windows のディスプレイ番号を指定し、画面内の9点とオフセットへマウスを移動可能に。

## 修正

- DPI の異なるマルチディスプレイ環境で、カーソルを基準とする表示位置のずれを修正。
- 設定保存・バックアップ・破損時の復旧を強化し、インポート失敗時に保存データと現在の動作設定を復元する処理を改善。
- 暗号化エクスポートの全永続項目を保持し、インポート時に実行可能設定の内容を確認する画面と処理上限を追加。
- 大きい設定を復元できないエクスポートファイルとして成功扱いで生成する問題を修正。上限超過を保存前に通知し、設定自体は切り詰めない。
- マクロの並行実行・停止・復旧処理を改善し、引数・マクロ入力などユーザーが指定する値のログへの露出を抑制。

## 更新・互換性

- `DropSendTo_win-x64_v1.4.1.zip` は .NET 10 Desktop Runtime が必要。`DropSendTo_Portable_win-x64_v1.4.1.zip` はランタイム同梱で、.NET の別途インストールは不要。
- ランタイム同梱版も設定を `%AppData%\DropSendTo` に保存する。更新前に設定を退避し、DropSendTo を終了して利用中と同じ配布形式のファイルへ置き換え、再起動する。サインイン起動登録を利用中なら実行ファイルを同じ場所に置く。
- 設定の暗号化形式は AES-GCM + PBKDF2-SHA256 200,000 iterations を維持。エクスポート対象の設定データは 8 MiB 以下、出力・入力ファイルは 16 MiB 以下。インポートは KDF 1,000,000 iterations 超を拒否する。以前作成したファイルも上限を超える場合はインポートできない。
- 大きい設定を退避するときは、アプリを終了して `config.json` と `config.json.bak` を別フォルダーへコピーする。旧版へ戻す場合も更新前の退避データを使用する。
- 更新確認ボタンはブラウザで公開ページを開く。自動ダウンロード・ファイル置換・再起動は行わない。v1.3.0 以前には更新確認画面がないため、この版への更新は GitHub Releases から行う。
- 検索語の `'`、`!`、`^`、`$`、`|` は検索演算子として使われる。記法と操作の詳細は同梱の `USER_GUIDE.md` を参照。
