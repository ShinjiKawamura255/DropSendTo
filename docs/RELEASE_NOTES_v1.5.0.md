# DropSendTo v1.5.0

公開日: 2026-10-23。v1.4.1 以降の変更。Windows 10 22H2 以降 / Windows 11、x64。

## 追加・改善

- **設定 → キーボード・マウス → 外部マクロのキー入力を受け付ける** を追加（既定OFF）。設定ソフトが合成キー入力を送る左手キーボードなどから、Prefix・スロットショートカット・検索ホットキーを操作できるようになりました。設定は即時反映され、バックアップ・暗号化エクスポートにも保存されます。
- スロット検索を、タイトル全体／検索キーワードの完全一致、部分一致、あいまい一致の順に表示するよう改善。全角空白・ハイフン・長音記号などの正規化後も適切に優先し、従来の検索条件・除外条件と同順位での並び順を維持します。

## 修正

- 単一ファイル配布時の `IL3000` 警告を解消。Windows サインイン時起動に登録するコマンドは、exe 直接起動と `dotnet` 経由の両方で従来の起動先を維持します。
- 設定保存失敗時に、画面と実行中の設定を変更前へ戻す処理を改善。バックアップ更新・復旧中の失敗でも保存済みの設定を保全し、対応外の将来バージョンの設定を上書きしないようにしました。
- 常駐中も CLI 引数付き起動を受け付け、保存済みの最後に手動選択したタブからコマンドを実行できるよう修正。追加のメインウィンドウは開きません。
- `COMMAND_WAIT` / `RUN_CAPTURE` の終了待ち・出力取得に共通のタイムアウトを適用し、キャンセル・異常終了時の処理を改善しました。
- ログを保存できない場合や設定を読み込めない場合に状態を通知する処理を改善しました。
- 配布ファイルの生成に失敗した場合も、既存の ZIP と `latest/` を保持できるよう配布処理を改善しました。

## 更新・互換性

- **通常版**: `DropSendTo_win-x64_v1.5.0.zip`。.NET 10 Desktop Runtime が必要です。
- **ランタイム同梱版**: `DropSendTo_Portable_win-x64_v1.5.0.zip`。.NET の別途インストールは不要です。設定保存先は通常版と同じ `%AppData%\DropSendTo` です。
- 設定形式のバージョンは37を維持します。既存設定を読み込んだ場合、外部マクロ入力の受け付けはOFFです。
- 更新前に設定を退避し、DropSendTo を終了して、利用中と同じ配布形式のファイルへ置き換えてください。サインイン時起動を登録済みの場合は実行ファイルを同じ場所へ置いてください。更新確認画面からこのリリースページを開くこともできます。
- 外部マクロ入力をONにすると、特定の機種に限らず他の自動入力ソフトも対象になります。キーを離してから切り替えてください。実機の左手キーボードごとの動作は未検証です。本ツール自身のマクロに対する検出制御とリモート接続先への入力優先は維持します。
- マクロの異常終了時は管理可能な子プロセスの停止を試みますが、権限制約や外部ツールの動作によって停止できない場合があります。詳細は同梱の `USER_GUIDE.md` を参照してください。
