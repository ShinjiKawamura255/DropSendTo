# REQUIREMENTS

## Background & Goal
Windows 用の軽量ドラッグ＆ドロップランチャを .NET 8（Windows 側）で実装する。エクスプローラーの SendTo 的な使い勝手で、登録スロット（既定 2x2／最大 8x4、4 レイヤー運用）へドロップすると関連アプリ／ショートカットを対象引数付きで起動し、スロットクリックや Prefix＋ショートカットでは任意のキーボードマクロとコマンド起動を組み合わせられる。

## Scope
- In: スロット登録/起動、レイヤー切替、レイアウト変更、キーボードマクロ連携、Prefix ベースのグローバルショートカット、常時最前面・半透明ウィンドウ、右クリックメニュー、設定永続化、ログ閲覧、適切なエラーハンドリング。
- Out: インストーラー/自動更新、クラウド同期、国際化、クロスプラットフォーム最適化。

## Use Cases
- UC-01: ファイル/フォルダをスロットへドロップして関連アプリを起動。
- UC-02: 右クリックからスロットにアプリ/ショートカット/引数を登録/編集/解除。
- UC-03: レイヤー（1-4）を切り替えて別の 2x2 セットを利用。
- UC-04: スロットクリックで直前にアクティブだったウィンドウへキーボードマクロを送り、その後に登録コマンドを実行。
- UC-05: Prefix を押下した後に登録済みショートカットでスロットを起動（必要に応じて対象レイヤーへ自動切替）。

## Functional Requirements (FR)
- FR-001: スロットグリッドは既定 2x2 としつつ 2〜8 行×2〜8 列の組み合わせをサポートし、4 レイヤー分を保持する（最大 64 スロット/レイヤー）。
- FR-002: ドロップされたパスを起動先の引数として渡す。
- FR-003: ウィンドウ右上のメニューボタンおよびウィンドウ右クリックメニューから、Open Config/Open Logs/Change Prefix/Slot Layout/常に最前面トグル/Exit を提供。
- FR-004: スロット登録内容・マクロ・現在レイヤー・ウィンドウ位置・常に最前面フラグを設定ファイルに永続化し、起動時に復元する。
- FR-005: コマンドライン引数（SendTo 相当）を受け取り、現在レイヤー内で最初に登録されたスロットへ渡して起動できる。
- FR-006: 起動失敗やマクロ失敗などのエラーはユーザーにメッセージを表示し、ログファイルにも記録した上でアプリは継続する。
- FR-007: ウィンドウはタイトルバー等を非表示にし、終了操作はメニュー経由のみとする。
- FR-008: レイヤーは UI ボタンから切替でき、マウスホイールでも前後へ循環切替可能である。
- FR-009: スロットはマウスオーバー/ドラッグ中/クリック時に視覚状態が変化する。
- FR-010: ウィンドウ位置は前回終了時から復元し、表示領域外の場合は自動的に画面内へ補正する。
- FR-011: スロットクリックによる起動はスロット単位で有効/無効を切替可能。
- FR-012: メニューボタンとレイヤーボタンはスロットと統一感のあるダークテーマ・角丸・ホバー/アクティブ反応を持つ。
- FR-013: ウィンドウ外枠は角丸とする。
- FR-014: メニューボタンから設定ファイルとログフォルダを既定アプリ/エクスプローラで開ける。
- FR-015: 登録ダイアログではタイトル/コマンド/引数テンプレート/マクロ/ショートカットを編集でき、参照ボタンで Windows のファイル選択ダイアログを開いてコマンドを指定するとファイル名をタイトルへ反映する。
- FR-016: ドラッグ中にレイヤーボタン上へ約800ms以上ホバーすると、そのレイヤーへ自動切替する。
- FR-017: スロットクリック/ドロップ時も視覚フィードバックを表示する。
- FR-018: Slot Size メニューで Small/Medium/Large/Custom を提供し、Small/Medium/Large では表示できるタイトル行数をそれぞれ 1 行・2 行・3 行に固定する（Small はステータスを同一行でオーバーレイ表示）。Custom ではスロット高さ・タイトル/ステータスのフォントサイズ・スロット間隔（余白、行列ステップ）を上下限付きで調整でき、切替時は縦幅/フォントを即時更新し設定へ保存する。既定値は Medium。
- FR-019: 各スロットにはキーボードマクロスクリプトを設定でき、クリック時はマクロ→コマンドの順で実行する。マクロのみ／コマンドのみも許容する。Macro Script では `KEY`/`TEXT`/`WAIT`/`MOUSE*`/`SET` 等に加え、`IF`/`ELSEIF`（または `ELSE IF`）/`ELSE`/`ENDIF` で多段の条件分岐を書ける。
- FR-020: 常に最前面フラグはメニューから切り替えられ、その状態を保存・復元する。
- FR-021: ログファイルは `%AppData%/DropSendTo/logs` にローテーション保存し、7日以上前のログを自動削除する。
- FR-022: Slot Layout メニューで行/列（2〜8）を直接入力でき、即時に UI と設定へ反映される。
- FR-023: 各スロットにグローバルショートカット（Prefix 押下後に入力するキー）を登録でき、Prefix 入力後 4 秒以内に該当ショートカットを押すと対象スロットがレイヤー切替込みで起動する。Prefix と同じ修飾キーを含むショートカットでも修飾キーを押し直さずに起動できる。
- FR-024: Prefix は Change Prefix ダイアログから編集でき、解析失敗時は既定の Ctrl+Q へフォールバックした上でユーザーへ通知する。Prefix の armed 状態は UI 左上のインジケーターで表示され、Prefix を再入力すると前面ウィンドウへ送出できる。
- FR-025: Arguments Template では `{args}` に加え `{clipboard}`（クリップボード文字列）、`{clipboard_args}`（最新のクリップボード文字列を行単位で引用付き展開）、`{clipboard_args:n}`（直近 n 行〈1〜20 行〉を古い順で引用付き展開）プレースホルダを利用できる。
- FR-026: ウィンドウはタスクトレイへ最小化でき、メニュー・Prefix+Shift+Enter・タスクトレイアイコンから最小化/復帰を操作できる。Prefix+Enter では最前面復帰と同時にタスクトレイからの復帰も行う。
- FR-027: Macro Script 実行時の同時実行モード（排他／割り込み実行／一時停止して割り込み）をメニューから選択でき、設定として保存・復元する。
- FR-028: Prefix+Ctrl+N で次レイヤー、Prefix+Ctrl+P で前レイヤーに切り替えるショートカットを提供する。既定は無効で、コンテキストメニューからオン/オフを切り替えられる。
- FR-029: Prefix+Enter でウィンドウを前面に復帰した後は矢印キーでスロットを選択し、Enter でそのスロットを実行できる。最初に矢印キーが押されるまでは選択状態にならず、Esc やマウス操作で選択モードを解除できる。
- FR-030: スロット編集モード（ツールバーの ✎ ボタン）を提供し、モード中は左上に「SLOT SETUP MODE」インジケーターを表示してクリック/ドロップ実行を無効化する。ドラッグ開始で編集中スロット名を示し、ターゲットスロットをホバーすると元位置にスワッププレビューを表示した上で、ドロップした瞬間にのみ確定する。レイヤーボタン上で 0.8 秒ホバーした場合は表示レイヤーを切り替え、別レイヤーとの交換や空スロットへの移動も同一操作で行える。
- FR-031: Macro Script では `REPLACE` コマンドを提供し、変数に格納した文字列を半角空白を含め任意の文字列へ置換または削除できる（検索/置換文字列はクォートで囲む）。さらに `REPLACE_REGEX` により、拡張正規表現と `$1` などのグループ置換、`IGNORECASE` などのオプション付きで文字列を加工できる。
- FR-032: ウィンドウがアクティブなときのみ有効な Emacs/vi ライクのキーボードナビゲーションを提供し、コンテキストメニュー「キーボード操作」から Emacs/vi を個別に有効/無効化できる（既定 OFF）。OFF の場合は矢印キーと Enter/Esc の基本操作だけが有効になる。
- FR-033: Macro Script に `PROMPT` コマンドを提供し、任意のメッセージを表示してユーザ入力を受け取り、指定変数へ格納できる。必要に応じ初期値を指定でき、キャンセル時はマクロを失敗として扱う。

## Non-Functional Requirements (NFR)
- NFR-001: .NET 8（Windows）で動作。WSL 上の .NET は不使用。
- NFR-002: Windows 10 22H2 以降で安定動作。起動 < 1s（温スタート）。
- NFR-003: 既定で常時最前面、黒基調、半透明（文字は読みやすさを維持）。ユーザー操作で常時最前面を解除しても UI が破綻しないこと。
- NFR-004: 設定はユーザープロファイル内（%AppData%）に保存。

## Constraints (CON)
- CON-001: UI フレームワークは Windows デスクトップ（WPF 推奨）。
- CON-002: ネットワーク不要。標準権限で動作。

## Acceptance Criteria (AC)
- AC-001: 選択中レイアウトで表示される全スロットの登録/起動/解除が再起動後も保持される。
- AC-002: ドロップおよびコマンドライン引数の双方で対象を起動でき、CLI 起動では登録済みスロットが見つからない場合のみ UI が表示される。
- AC-003: ウィンドウは既定で常時最前面・半透明で文字の視認性を損なわず、メニューから常時最前面を切り替えても UI が保たれる。
- AC-004: 例外や起動失敗時はアプリが落ちず、ユーザーへエラーダイアログを表示し、ログに記録する。
- AC-005: タイトルバーなしでもメニューから終了でき、誤クリックで終了しない。
- AC-006: レイヤーはボタン/ホイールで循環切替でき、現在レイヤーのハイライトが更新される。
- AC-007: スロットの hover/drag/クリック状態が視覚で判別できる。
- AC-008: 再起動後にウィンドウ位置と常時最前面設定が復元され、常に画面内に表示される。
- AC-009: クリック実行の有効/無効とマクロスクリプトがスロット単位で設定・保存される。
- AC-010: メニューボタンから config.json とログフォルダを既定アプリ/エクスプローラで開ける。
- AC-011: Slot Layout メニューで選んだ行列構成が即時に UI/設定へ反映され、再起動後も保持される。
- AC-012: Prefix を変更・保存でき、Prefix 押下後の 4 秒以内に登録ショートカットを入力すると該当スロットがレイヤー切替込みで起動し（同じ修飾キーは押し直さなくてもよい）、Prefix 再入力で前面ウィンドウへ送出できる。インジケーターはウィンドウ左上で状態を示す。
- AC-013: エクスプローラーでコピーしたパスを `{clipboard_args}` が正しく引用付きで展開し、`{clipboard}` で文字列として扱える。
- AC-014: `{clipboard_args:n}` に n（例: 3）を指定した場合、直近のコピー履歴から n 行のみが古い順に引用付きで渡され、それ以外は含まれない。
- AC-015: `Minimize to Tray` メニューおよび Prefix+Shift+Enter でウィンドウがタスクトレイへ格納され、Prefix+Enter またはタスクトレイアイコン左クリックで表示が復帰する。
- AC-016: Macro 実行モードが「排他」のときは従来通り別スロットのマクロ開始を禁止し、「割り込み実行」では実行中マクロをキャンセルして新規マクロが直ちに開始され、「一時停止して割り込み」では実行中マクロが安全に一時停止し、新規マクロ完了後に自動再開する。モード変更はメニューで即時反映され、再起動後も保持される。
- AC-017: コンテキストメニューの Emacs/vi トグルを変更すると即時反映され、Enter/Ctrl+J/Ctrl+M などの確定キーでも切り替え・メニュークローズが行われる。設定は保存・再起動後も復元され、ON で対応キーが、OFF で矢印キーのみが有効化される。
